# Automatization Testing con Selenium

Proyecto de QA Automation con Selenium para la pagina web **Sause Demo** con el objetivo de realizar pruebas automatizadas dentro de la página. Se realizan pruebas de login, carrito, y otras pruebas de navegación, para el curso de Talento Tech.

## Tecnologias

- Python
- Pytest
- Selenium
- Git
- Github

## Instalación

** instalación de dependencias:**

``` python+
pip install pytest
```

```python
pip install pytest-html
```

```python
pip install selenium
```

## Ejecución de pruebas

```python
pytest
```

## Casos de prueba
- Login exitoso.
- Agregar producto al carrito.
- Verificar producto en el carrito.
